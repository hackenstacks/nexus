    🧭 NeXuS Compass — Gen6 graphics · apk-world hygiene · node-guards · Chromium¶

    Stamped 2026-07-20 · Anon shutting down — pick up here

    Big session. Fixed the E6520's video/graphics end-to-end (VA-API hardware decode, GL threading, hardware cursors, Chromium GPU-raster garbage), cleaned a partially-broken apk world without a single --force or destructive cascade, hardened the apk-sink to tolerate a dirty world, and distilled the whole thing into two universal node tools. Principles: Sane · Simple · Secure · Stealthy · Sustainable · Beautiful (6 now; Sustainable inserted before Beautiful — confirmed by Anon this session).

    ✅ DONE this session¶

    Gen6 graphics — VERIFIED working end-to-end¶

    Hardware: Dell E6520, Intel Sandy Bridge / HD Graphics 3000 (SNB GT2, Gen6), crocus, OpenGL 3.3 / Mesa 26.1.1. No Vulkan (ANV needs Gen7+). Single Intel GPU, no NVIDIA. - VA-API HW video decode now live: installed libva-intel-driver + libva-utils (Gen6 uses the legacy i965 driver — NOT intel-media-driver, which is Gen8+ and silently won't load). vainfo confirms H.264 (baseline/main/high) + MPEG-2 decode (+H.264 encode). - ~/.config/mpv/mpv.conf: hwdec=no → hwdec=vaapi, vo=gpu. Tested: an h264 940x1280 clip played clean, no garbage, LOW CPU (= real GPU offload). This build has no dmabuf-wl vo — use gpu/gpu-next on Wayland, drm on bare TTY. - ~/.config/fish/conf.d/nexus-graphics.fish (NEW): exports LIBVA_DRIVER_NAME=i965, MESA_GLTHREAD=true, and CHROMIUM_USER_FLAGS. - nexus-wayland-launcher.sh: WLR_NO_HARDWARE_CURSORS is now NVIDIA-only → Intel gets hardware cursors. Also added foot --server startup (see below). - RAM = nothing to do: nexus-dmi-mem.py read it safely → 4 GB ChannelA + 8 GB ChannelB @ 1333 MT/s = dual-channel FLEX (8 GB interleaved full-bandwidth + 4 GB single). 1333 is the SNB max. Fully-symmetric would need 2×8 GB (marginal iGPU gain — not worth $).

    Chromium garbage — FIXED (Firefox was always fine)¶

    chrome://gpu dump (~/Downloads/about-gpu-2026-07-20*.txt) showed Chromium on ANGLE→OpenGL ES 3.0 on crocus with Rasterization: Hardware accelerated — HW raster on SNB paints garbage. Fix persisted in nexus-graphics.fish: set -gx CHROMIUM_USER_FLAGS "--disable-gpu-rasterization" (Alpine chromium wrapper appends CHROMIUM_USER_FLAGS — no root). Keeps HW compositing + HW video decode; only raster → CPU. Anon confirmed clean. (Launcher/fuzzel-spawned chromium needs next Wayland session to inherit the env; terminal-launched picks it up now.)

    apk world hygiene — 4 errors → 3 benign, NO force, NO cascade damage¶

    Root cause of "all sink installs failing": a dirty apk world made apk exit non-zero on every op; the sink misread that as per-package conflict. - Removed apk-snap (btrfs commit-hook) — root is ext4-on-LVM, so it errored every apk run + spammed subvolume is not a btrfs. Cascaded out snapper + btrfs-progs-libs (dead weight); btrfs-progs tools kept (no btrfs mounts anywhere; sdb1 3.6T unformatted). - incus flavor collision FIXED: had both incus-openrc (LTS) and incus-feature-openrc installed → both own /etc/init.d/incusd. Removed the mismatched incus-feature-openrc (init for a incus-feature daemon that isn't installed); incus-openrc now owns incusd, matching the installed LTS incus. - 3 benign collisions LEFT baselined (removing cascades badly): 3proxy-doc⨯libproxy-doc, outils-doc⨯uutils-coreutils-doc, and freeradius-client⨯ppp-radius — the RADIUS one is STUCK because removing freeradius-client cascades to 58 packages (nagios-plugins-all → all nagios plugins + net-snmp). Deliberately not touched. - Discipline throughout: apk del -s simulate before every delete, never --force (Anon's hard rule: force/override "cripples a system for life").

    nexus-apk-sink.sh — HARDENED for a dirty world (backup .bak-20260719_183534)¶

    (1) baseline pre-existing apk error-lines via apk add --simulate busybox; (2) flag a pkg as conflict only if it emits MORE errors than baseline (not on exit code); (3) judge install success by apk info -e STATE not exit code. Result: netscanner sink then walked all 33 pkgs, 0 conflict / 0 dropped.
