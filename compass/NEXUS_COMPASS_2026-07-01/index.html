    2. Touchpad — Alps GlidePoint¶

    Device: AlpsPS/2 ALPS GlidePoint (/dev/input/event7)

    Root cause: sensors (lm-sensors) hammering the hardware bus caused PS/2 interrupts to drop, making the touchpad cut out.

    Fix: Removed sys-temp from Dracula plugins — touchpad stable since.

    Permanent fix for Disable-w-trackpointing (not yet applied — touchpad stable without it): 

    xinput set-prop "AlpsPS/2 ALPS GlidePoint" "libinput Disable While Trackpointing Enabled" 0
doas sh -c 'cat > /etc/X11/xorg.conf.d/40-touchpad.conf << EOF
Section "InputClass"
    Identifier "Alps GlidePoint"
    MatchIsTouchpad "on"
    Driver "libinput"
    Option "DisableWhileTrackpointing" "false"
    Option "Tapping" "on"
EndSection
EOF'
