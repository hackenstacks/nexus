    🧭 NeXuS Compass — 2026-07-28 — Universal API Proxy + NeXuS Web Server¶

    Theme: Built the sovereign serving+key layer. One portable pure-Python HTTPS server that serves any app AND fronts every AI provider through one /api/* proxy that injects keys server-side (no key ever in the browser).     3. UNIVERSAL API SERVER (the leap)¶

    • Dynamic providers from the env file — no code edit: scan for PROVIDER_<ID>_BASE_URL (+_API_KEY optional → keyed/keyless, _KIND, _LABEL). Registered on the fly, appears in /api/providers, callable at /api/llm/<id>/v1/chat/completions. No restart.
    • Secure .local.env: precedence process-env > .local.env > nexus.env > legacy. Guards: never web-served (static 404s any .env/.key/.pem/dotfile even inside docroot); auto-.gitignore (startup appends secret patterns to a .gitignore in the folder, append-only); never logged/returned; chmod-600 warning. Template .local.env.example.
    • Routes: /api/health, /api/providers (sanitized), /api/models/{image,text} (Pollinations), /api/models/provider/{id} (NEW — live per-provider /models, normalized), /api/pollinations/image (streamed), /api/llm (body-style) + /api/llm/{provider}/v1/chat/completions (vanilla OpenAI body).
    • CSP fix: added worker-src 'self' blob: (app web-workers were being blocked).

    🗝️ Gotchas / notes¶

    • Server reads secrets on-demand → adding a key to nexus.env needs no restart; adding a route (code) does need a restart. Launch it with run_in_background: true + no exec (exec/& get reaped).
    • curl -I (HEAD) is NOT implemented → check headers with curl -D - … -o /dev/null (a GET).
    • fish shell prints exit 144 noise on piped/pkill commands — output still valid.
    • Provider ids must match server registry; grok = Pollinations-backed (no xAI key on file); AI Horde file entry was just z → uses keyless anon 0000000000.
